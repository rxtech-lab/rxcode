# Cloudflare Usage

Track Cloudflare account billing, zone traffic, Worker invocations or R2 storage. Choose a Cloudflare membership in the connection settings, or supply an account ID. Leave the resource empty for account usage. A Billing Read API token can provide billing access even when your OAuth session has expired.

RxCode adds credentials to requests sent to api.cloudflare.com. Your integration keeps its existing Keychain entries.
