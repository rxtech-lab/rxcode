# Vercel Usage

Track Vercel billing by currency and service over the last 30 days. Choose a billing team in connection settings, enter its ID or slug, or use your default team. Enter a project ID to filter billed charges. An optional AI Gateway credential adds the team's remaining credit balance.

RxCode adds credentials to requests sent to api.vercel.com, ai-gateway.vercel.sh. Your integration keeps its existing Keychain entries.
