# 项目钩子

钩子（Hooks）会在聊天会话生命周期的关键节点自动运行一条命令。你可以用它在线程
开始时注入上下文（例如当前的 git 状态、待办事项或环境说明），并在一轮对话结束时
运行清理或通知命令。钩子按**项目**单独配置。

## 在哪里配置

打开 **设置 → 通用 → 钩子**，选择一个项目，然后点击 **管理钩子…**。编辑器与
“运行配置”类似：左侧是按触发时机分组的钩子列表，右侧是详情表单。每个钩子都有名称、
**启用** 开关、**触发时机**、shell **命令**、可选的**工作目录**，以及可复用的
**环境预设**（手动键值对或加载的 `.env` 文件）。

命令通过 `/bin/zsh -lc` 运行，因此你的登录 `PATH`（bun、pnpm、pyenv 等）都可用，
与集成终端一致。

## 触发时机

共有三种触发时机：

- **会话开始前（Before Session Start）** — 仅在全新线程开始第一轮对话时运行一次。
  命令的标准输出会被**注入到该轮对话的智能体上下文**中，作为背景信息。
- **会话停止前（Before Session Stop）** — 在流式输出停止时（智能体回复完成，或你
  取消）运行。其输出会**显示在聊天中并随线程一起保存**为上下文块，但不会触发新的
  对话轮次。
- **会话停止后（After Session Stop）** — 在流式输出停止、线程已结束后运行。其输出
  **仅作展示** —— 不会传回会话。

## 聊天中的状态

每次钩子运行都会在桌面端和移动端的消息列表中以卡片形式内联显示：运行时显示进度
指示器，随后显示成功或错误标记。展开卡片可查看命令输出。非零退出码会标记为错误，
但不会阻止会话继续。

## 说明

- 已禁用的钩子永远不会运行。
- “会话开始前”仅对新线程运行 —— 在已有线程中继续发送消息不会再次触发它；而停止类
  钩子会在每轮对话结束时运行。
- 对于 Claude Code 线程，钩子卡片会在实时会话期间显示；Claude 的线程历史由 CLI
  管理，因此重新打开的 Claude 线程可能不会显示过去的钩子卡片。开始钩子的上下文注入
  对所有提供方均有效。
